## 30 秒看效果

浏览器直接打开 `preview/index.html` —— 11 个关键页面的界面预览，数字和真机一致。

## 5 分钟跑起来

1. 装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. **导入项目** → 目录选本文件夹 `chishenme-miniprogram`
3. **AppID**：点「测试号」或「使用游客模式」，有自己 AppID 就填自己的
4. **后端服务**：不使用云服务
5. 编译完成后，**详情 → 本地设置**，勾选「不校验合法域名…」
6. 按下面顺序点一遍：

```
注册（填昵称）→ 位置（模拟器拿不到定位，点手动选区域）
→ 欢迎信（我自己逛逛）→ 首页饭流 → 点饭卡看详情
→ 收藏 / 就吃这个 → 底部＋记一顿 → 我的 → 我的餐单 → 我吃了
→ 我的饭历 → 消费统计
```

## 技术说明

- 原生微信小程序，无框架依赖、无 npm 依赖
- 全部数据是本地假数据，业务规则集中在 `utils/store.js`；接后端只需替换这一个文件
- 视觉基准：奶油杏橙（`#FF8B3D` / `#FFF8F1` / `#FFD8B5`），令牌在 `app.wxss` 顶部
- V1 不含：搜索、评论、点赞、粉丝数、私信、团购、排行榜、签到


## 开源仓库安全配置说明

本仓库已移除真实微信小程序 AppID 与云开发环境 ID，不含部署密钥或用户数据。

- 使用微信开发者工具导入此目录。`project.config.json` 默认使用 `touristappid` 作为开发占位值；在本地替换为自己的 AppID（不要把此修改推送到公开仓库）。
- 在本地将 `utils/cloudapi.js` 的 `DEFAULT_ENV` 改为自己的云开发环境 ID，或在初始化时通过 `setEnv(envId)` 注入。
- 云函数代码位于 `cloudfunctions/api/`；部署需使用自己的微信云开发环境。
- `utils/mock.js` 仅包含用于 UI 演示的虚构样例，不是用户真实数据库导出。
